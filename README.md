# Pemweb

Source code Tugas Individu 3 Pemrograman Web.

## Menjalankan

Buka `task_3/index.html` di browser. Halaman pendaftaran menggunakan metode GET dan mengarah ke `task_3/detail.html`.

## Struktur

- `task_3/index.html` — halaman pendaftaran
- `task_3/detail.html` — halaman detail dengan data dummy
- `task_3/style.css` — stylesheet responsif bersama
